## 1. 선정 기준 및 가중치

| 기준 | 가중치 | 설명 |
|------|--------|------|
| FDD 경험 | 30% | FDD/CDD 수행 경력 (건수, 연차) |
| 기술 역량 | 20% | Excel/데이터 분석 도구 활용 능력, IT 리터러시 |
| 협업 의지 | 25% | 피드백 제공 적극성, 커뮤니케이션 빈도 |
| 데이터 준비도 | 15% | 테스트용 TB/GL 데이터 보유 여부 및 품질 |
| 규모 적합성 | 10% | 중소형 딜 중심 (연매출 100억~5,000억 대상 기업) |

**총합: 100%**

## 3. 1차 컨택 이메일 템플릿

```
제목: [Auto FDD] Beta Pilot 참여 요청 — FDD 자동화 도구 사전 체험

안녕하세요, {파트너사명} {담당자명}님.

{발신자 소속/이름}입니다.

당사에서 개발 중인 FDD(Financial Due Diligence) 자동화 도구 'Auto FDD'의
Beta Pilot 프로그램에 참여하실 파트너를 모집하고 있어 연락 드립니다.

■ Auto FDD 주요 기능:
  - TB/GL 자동 인제스트 및 계정 매핑
  - QoE (Quality of Earnings) 자동 분석
  - NWC / Net Debt 자동 분류 및 계산
  - PPT/Word 보고서 자동 생성

■ Beta Pilot 기간: 약 4주 (일정 협의 가능)
■ 참여 조건: 테스트용 딜 데이터 1~2건 제공, 주 1회 피드백 제출

참여 의향이 있으시면 회신 부탁드립니다.
자세한 안내 자료를 별도 전달 드리겠습니다.

감사합니다.
{발신자 서명}
```

## 4. 제안서 체크리스트
