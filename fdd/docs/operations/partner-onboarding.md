# Auto FDD — 파트너 온보딩 가이드

> 작성: Sprint 12 | 대상: 베타 파일럿 파트너사

---

## 1. 온보딩 프로세스 개요

```
Day 0: 계정 발급 → Day 1: 교육 → Day 2~3: 샘플 딜 실습 → Day 4~5: 실제 딜 적용
```

| 단계 | 소요 | 담당 | 산출물 |
|------|------|------|--------|
| 1. 파트너 등록 | 30분 | Admin | 계정 정보 |
| 2. 초기 교육 | 2시간 | PM | 교육 완료 확인서 |
| 3. 샘플 딜 실습 | 1일 | 파트너 | 실습 딜 완료 |
| 4. 실제 딜 적용 | 2~3일 | 파트너+지원 | 첫 FDD 보고서 |
| 5. 피드백 수집 | 30분 | PM | 피드백 양식 |

---

## 2. 파트너 계정 생성

### 2.1 Admin 계정으로 로그인

```
URL: https://fdd.example.com
ID: admin@company.com
```

### 2.2 사용자 등록

**API 직접 등록:**
```bash
curl -X POST https://fdd.example.com/api/v1/auth/users \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "partner@partnerfirm.com",
    "password": "임시비밀번호(최초로그인시변경)",
    "display_name": "홍길동 (파트너사)",
    "role": "ANALYST"
  }'
```

**역할 가이드:**

| 역할 | 용도 | 권한 |
|------|------|------|
| VIEWER | 읽기 전용 검토자 | 딜 조회, 보고서 열람 |
| ANALYST | FDD 실무자 | 딜 조회, 업로드, 분석, 보고서 생성 |
| REVIEWER | 리뷰어/파트너 | ANALYST + 정의 승인, QA 리뷰 |
| ADMIN | 시스템 관리자 | 전체 권한 |

> 베타 파트너에게는 **ANALYST** 역할 권장. 리뷰 필요 시 **REVIEWER** 부여.

## 4. 교육 커리큘럼

### 4.1 기본 교육 (2시간)

| 시간 | 내용 |
|------|------|
| 0:00~0:20 | 시스템 소개, 로그인, UI 탐색 |
| 0:20~0:50 | 딜 생성 (Completion Accounts / Locked Box) |
| 0:50~1:10 | TB/GL 업로드 및 인제스트 |
| 1:10~1:30 | 계정 매핑 (자동 제안 + 수동 조정) |
| 1:30~1:50 | QoE/NWC/Net Debt 분석 |
| 1:50~2:00 | 보고서 생성 및 다운로드 |

### 4.2 실습 딜

교육 후 아래 샘플 데이터로 실습:

1. **딜 생성**: "교육용 딜 - [파트너명]"
   - 유형: COMPLETION_ACCOUNTS
   - 통화: KRW
   - 기준일: 2025-12-31
   - 분석기간: 2025-01-01 ~ 2025-12-31

2. **업로드**: 제공된 샘플 TB/GL 파일
   - `sample-tb.xlsx` (시산표 20계정)
   - `sample-gl.xlsx` (총계정원장 50전표)

3. **분석 실행**: 매핑 → QoE → NWC → Net Debt → 보고서

## 5. 데이터 준비 가이드

### 5.1 시산표 (TB) 형식

| 열 | 필수 | 설명 |
|----|------|------|
| 계정코드 | O | 계정 고유 코드 |
| 계정명 | O | 계정 이름 |
| 차변 | O* | 차변 잔액 |
| 대변 | O* | 대변 잔액 |

> *차변/대변 또는 잔액 열 중 하나 필수

### 5.2 총계정원장 (GL) 형식

| 열 | 필수 | 설명 |
|----|------|------|
| 전표번호 | O | 전표 고유 번호 |
| 전표일자 | O | YYYY-MM-DD 형식 |
| 계정코드 | O | 계정 고유 코드 |
| 계정명 | - | 계정 이름 |
| 차변 | O* | 차변 금액 |
| 대변 | O* | 대변 금액 |
| 적요 | - | 거래 설명 |
| 거래처 | - | 거래처명 |

> *차변/대변 또는 금액 열 중 하나 필수

### 5.3 주의사항

- 파일 형식: **.xlsx만** 지원 (.xls, .csv 불가)
- 헤더: **1행에 반드시 열 이름** (한글/영문 모두 인식)
- 금액: 숫자만 (통화 기호 ₩, $ 제거)
- 날짜: YYYY-MM-DD 권장 (YYYY/MM/DD, YYYY.MM.DD도 가능)
- 빈 행: 자동 건너뜀
