마케팅 (Marketing)

📢 MARKETING

잠재 매수자에게 접촉하고, NDA를 체결하며, CIM을 배포합니다. 3가지 뷰(Grid/Timeline/Kanban)로 마케팅 활동을 실시간 추적합니다.

📊

Grid View (현황판)

매수자별 진행 상태를 카드 형태로 한눈에 파악합니다. 탈락/진행중/우승 상태별 색상 구분과 DART 기반 재무 미니 테이블을 제공합니다.

📅

Timeline View

마케팅 활동을 시간 축으로 시각화합니다. 첫 접촉부터 NDA 체결, Target Meeting까지 6단계 진행을 타임라인에서 확인합니다.

📋

Kanban View

IDENTIFIED → EMAIL_SENT → NDA_SIGNED → TARGET_MEETING 등 단계별 컬럼에서 카드를 드래그하여 진행 상태를 업데이트합니다.

🔗

DART 연동

공개 기업의 재무정보(매출, 영업이익, 순이익, 부채비율)를 DART API에서 자동 조회하여 매수자 평가에 활용합니다.

📝

마케팅 로그

매수자별 접촉 이력(이메일, 전화, 미팅)을 자동 기록합니다. 바이어 반응(매우 긍정~매우 부정 5단계), 조건 매칭 수준도 함께 기록합니다.

📄

NDA 관리

One-Way/Mutual NDA를 버전별로 관리합니다. DRAFT → SENT → SIGNED → EXPIRED 상태 흐름을 추적하고 만료일 알림을 제공합니다.
