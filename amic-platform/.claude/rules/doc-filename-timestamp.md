# 문서 파일명 타임스탬프 규칙 (필수)

> 생성: 2026-02-22 01:37

## 핵심 원칙

**문서 파일명 서두에 반드시 마지막 수정 시점의 타임스탬프를 기재한다.**

## 규칙 상세

### 1. 파일명 형식
```
YYYYMMDD_HHMM_{문서명}.md
```
예: `20260222_0137_My_Document.md`

### 2. 타임스탬프 = 수정 시점 (작성 시점 아님)
- 문서를 **수정(Edit/Write)할 때마다** 파일명의 타임스탬프를 **수정 당시 시간**으로 갱신한다
- 최초 작성 시에도 작성 시점의 시간을 사용한다
- **작성 시점이 아니라 수정 시점**이 핵심

### 3. 시간 확인 방법
문서를 수정하기 직전에 반드시 PowerShell로 현재 시간을 확인한다:
```powershell
Get-Date -Format "yyyyMMdd_HHmm"
```

### 4. 수정 시 파일명 갱신 절차
```
1. PowerShell로 현재 시간 확인
2. 문서 내용 수정
3. 파일명의 타임스탬프 부분을 현재 시간으로 변경
   예: 20260210_2203_Plan.md → 20260222_0137_Plan.md (수정 시)
```

### 5. 적용 범위
- `docs/` 하위 모든 `.md` 파일
- `review/` 하위 모든 `.md` 파일
- Plan mode에서 생성하는 플랜 파일

### 6. 예외 (타임스탬프 불필요)
- `docs/INDEX.md` — 색인 파일
- `review/INDEX.md` — 리뷰 색인 파일
- `CLAUDE.md`, `CLAUDE.local.md`, `README.md`, `MEMORY.md` — 시스템 파일
- 코드 파일 (`.ts`, `.py`, `.tsx` 등)

### 7. 위반 방지
- 타임스탬프 없는 문서 파일 생성 금지
- 문서 수정 시 파일명 갱신 누락 금지
- PowerShell 시간 확인 없이 임의 시간 기재 금지
