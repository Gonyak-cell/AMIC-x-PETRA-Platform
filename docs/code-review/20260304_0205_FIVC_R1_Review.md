### [ISS-003] make_service_token() try 블록 외부 호출 — [Major/HIGH] — P1
- **파일**: si_mapping_service.py:339
- **관점**: R4-1 에러 처리

- **수정안**: try 블록 범위를 L339로 확장 + except에 `RuntimeError` 추가

### [FI-VC-01] datetime.now(UTC).year 중복 호출 — [Major/HIGH] — P1
- **파일**: si_mapping_service.py:381
- **관점**: R3-1 데이터 흐름
- **검증 추적**: 1.✓ Glob → 2.✓ Read → 3.✓ Grep → 4.✓ SC → 5.✓ 증거
- **이슈**: `range(datetime.now(UTC).year, datetime.now(UTC).year - 3, -1)`에서 `.year`를 2회 호출. UTC 자정(KST 09:00) 경계에서 연도 불일치 → `responses[1:4]` 인덱싱 오류.
- **수정안**: `current_year = datetime.now(UTC).year` 변수화

### [DL-02] _strip_ksic_prefix와 인덱스 키 간 비대칭 — [Major/HIGH] — P1
- **파일**: si_mapping_service.py:108-115,153,565-591

- **검증 추적**: 1.✓ Glob → 2.✓ Read → 3.✓ Grep → 4.✓ SC → 5.✓ 증거
- **이슈**: 쿼리 코드에만 `_strip_ksic_prefix()` 적용(L153), 인덱스 키 구축 시 미적용(L565-591). 알파벳 접두사 KSIC("J58211")가 포함된 기업 매칭 실패.
- **수정안**: `_build_ksic_index()`에서 인덱스 키에도 `_strip_ksic_prefix()` 적용
