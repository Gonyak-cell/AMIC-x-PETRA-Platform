# 개발 환경 포트 가이드: 5173 vs 3000

> 작성일: 2026-02-17 19:07:00

## 요약

| | **3000** (Nginx) | **5173** (Vite) |
|---|---|---|
| **서비스** | Nginx 리버스 프록시 | Vite 개발 서버 |
| **API 라우팅** | Docker 내부 네트워크 (`fdd-api:8000`) | Vite 프록시 (`localhost:8000`) |
| **로그인** | **정상 작동** | **실패** (Docker 환경) |
| **권장 사용** | Docker Compose 전체 실행 시 | 프론트엔드 로컬 실행 시 |

---

## 아키텍처

### Port 3000 — Nginx 리버스 프록시

```
브라우저 → localhost:3000 → Nginx 컨테이너
    ├── /           → frontend:5173 (Vite 컨테이너)
    ├── /api/fdd/   → fdd-api:8000  (Docker 내부 네트워크)
    ├── /api/kiis/  → kiis-api:8000 (Docker 내부 네트워크)
    └── /api/im/    → im-api:8000   (Docker 내부 네트워크)
```

- **설정 파일**: `nginx/dev.conf`
- Docker 서비스명(`fdd_api`, `kiis_api`, `im_api`)으로 라우팅
- 모든 요청이 동일 출처(`localhost:3000`)에서 처리됨
- 쿠키(httpOnly)가 정상적으로 설정/전송됨

### Port 5173 — Vite 개발 서버

```
브라우저 → localhost:5173 → Vite 컨테이너
    ├── /           → Vite 자체 서빙
    ├── /api/fdd/   → localhost:8000 ← ❌ 컨테이너 내부에 없음!
    ├── /api/kiis/  → localhost:8001 ← ❌ 컨테이너 내부에 없음!
    └── /api/im/    → localhost:8002 ← ❌ 컨테이너 내부에 없음!
```

- **설정 파일**: `amic-platform/vite.config.ts` (server.proxy)
- `localhost`가 **프론트엔드 컨테이너 자기 자신**을 가리킴
- 백엔드는 별도 컨테이너(`fdd-api`, `kiis-api`, `im-api`)에서 실행 중
- 따라서 Vite 프록시가 백엔드를 찾지 못하고 **연결 실패**

## 로그인 실패 원인 (5173)

### 근본 원인

`vite.config.ts`의 프록시 타겟이 `localhost:8000`으로 하드코딩되어 있음:

```ts
// amic-platform/vite.config.ts:54-58
"/api/fdd": {
  target: "http://localhost:8000",   // Docker 컨테이너 내부에서는 자기 자신
  changeOrigin: true,
  rewrite: (path) => path.replace(/^\/api\/fdd/, "/api/v1"),
},
```

Docker 컨테이너 내부에서 `localhost:8000`은 프론트엔드 컨테이너 자체를 가리키므로, FDD 백엔드(`fdd-api:8000`)에 도달하지 못한다.

### 로그인 요청 흐름 비교

**3000 포트 (성공):**
```
POST localhost:3000/api/fdd/auth/login
  → Nginx: rewrite /api/fdd/auth/login → /api/v1/auth/login
  → proxy_pass http://fdd_api:8000   ← Docker 내부 네트워크 (정상)
  ← Set-Cookie: access_token=...; HttpOnly; SameSite=Lax
  ← 200 OK
```

**5173 포트 (실패):**
```
POST localhost:5173/api/fdd/auth/login
  → Vite proxy: target http://localhost:8000
  → localhost:8000 = 프론트엔드 컨테이너 자체 (백엔드 없음)
  ← ECONNREFUSED 또는 502 Bad Gateway
```

## 권장 사용 방법

### 방법 1: Docker 전체 실행 (권장)

```bash
docker compose up -d
# → http://localhost:3000 으로 접속
```

모든 서비스가 Docker 네트워크 안에서 통신하므로 안정적.

### 방법 2: 프론트엔드만 로컬 실행

```bash
# 백엔드만 Docker로 실행
docker compose up fdd-api fdd-db kiis-api kiis-db kiis-redis kiis-es im-api im-db im-redis -d

# 프론트엔드는 로컬에서 직접 실행
cd amic-platform
npm run dev
# → http://localhost:5173 으로 접속
```

이 경우 Vite 프록시의 `localhost:8000`이 Docker가 호스트에 노출한 포트를 가리키므로 정상 작동.

## 관련 파일

| 파일 | 역할 |
|------|------|
| `docker-compose.yml` | Docker 서비스 정의 (포트 매핑 포함) |
| `nginx/dev.conf` | Nginx 리버스 프록시 설정 (3000 포트) |
| `amic-platform/vite.config.ts` | Vite 프록시 설정 (5173 포트) |
| `fdd/backend/app/api/auth.py` | 로그인 API + httpOnly 쿠키 설정 |
| `fdd/backend/app/auth/dependencies.py` | JWT 인증 의존성 (쿠키 폴백) |
| `fdd/backend/app/config.py:25` | CORS 허용 출처 (`cors_origins`) |
