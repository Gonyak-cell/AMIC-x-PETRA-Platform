# 기관전용 사모펀드 GP/운용사 데이터소스 조사 보고서

> 작성: 2026-02-22 16:35
> 배경: KOFIA DIS 기준가격 공시에 미포함된 기관전용 사모펀드 운용사(에이티유파트너스 등) 조회 방안

---

## 1. 배경

현재 KIIS 모듈은 KOFIA(금융투자협회) DIS 시스템의 기준가격 데이터를 사용한다.
이 데이터는 **공모펀드 + 기준가격 공시 의무가 있는 일부 사모펀드**만 포함하며,
에이티유파트너스 같은 기관전용 사모펀드 운용사는 검색 불가 상태이다.

---

## 3. 상세 분석

### 3-1. 공공데이터포털 — 금융통계자산운용사정보 API (1순위)

- **API URL**: `https://apis.data.go.kr/1160100/service/GetAsseManaCompInfoService/`
- **오퍼레이션**: 일반현황 조회, 재무현황 조회, 주요 경영지표 조회 (3개)
- **제공 데이터**: 운용사명, 법인등록번호, 금융회사코드, 임직원수, 인가일자, 자본금, 총자산, 영업수익, **AUM(운용자산), 펀드수, 수탁고**
- **API 키**: 공공데이터포털에서 무료 발급, 자동승인
- **트래픽**: 개발 10,000건/일
- **갱신 주기**: 분기별 (업무보고서 기반)
- **구현 난이도**: **쉬움** — 표준 REST API, JSON 응답

### 3-2. 공공데이터포털 — 금융회사기본정보 API (2순위)

- **API URL**: `https://apis.data.go.kr/1160100/service/GetFnCoBasiInfoService/getFnCoOutl`
- **제공 데이터**: 금융회사명, 영문명, 사업자등록번호, 법인등록번호, 설립일자, 주소, 연락처, 종업원수, 상장정보
- **사모펀드 포함**: **집합투자업자(자산운용사) 포함 확인됨**
- **갱신 주기**: 일 1회 (영업일 오후 1시 이후)
- **구현 난이도**: **쉬움**

### 3-3. FreeSIS 종합통계 (3순위)

- **URL**: `https://freesis.kofia.or.kr/`
- **관련 메뉴**: 펀드 > 운용사통계 > "기관전용 사모펀드" (별도 카테고리)
- **제공 데이터**: 운용사별 설정잔액, 자금유출입, 신규설정 현황
- **API 미제공**: 웹 UI + 엑셀 다운로드만 가능
- **갱신 주기**: 일별~월별

### 3-4. DART 펀드공시 (4순위)

- **URL**: `https://dart.fss.or.kr/dsab005/main.do`
- **제공 데이터**: 자산운용보고서 원문 (PDF/HTML), 포트폴리오, 수익률, AUM
- **사모펀드 포함**: 자산운용보고서 제출 의무에 의해 포함
- **API**: 펀드 전용 OpenAPI **없음** — 기업 공시 검색 API(DS001)만 존재
- **구현 난이도**: **어려움** — PDF/HTML 파싱 필요

## 4. 구현 권장 전략

### Phase 1: 즉시 구현 (1~2일)

**공공데이터포털 REST API 2개를 조합**

```
금융회사기본정보 API → 모든 등록 운용사 기본 프로필
         +
금융통계자산운용사정보 API → AUM, 펀드수, 재무현황
         ↓
    금융회사코드/회사명으로 조인
```

- KIIS 백엔드에 `/api/v1/gp/registry` 엔드포인트 추가
- 기존 KOFIA GP 데이터와 병합하여 커버리지 확대
- API 키 발급 → `.env`에 `DATA_GO_KR_API_KEY` 추가

### Phase 2: 중기 보완 (1~2주)

**FreeSIS 통계 데이터 수집 자동화**

- "기관전용 사모펀드" 카테고리에서 운용사별 설정잔액 확보
- Celery 배치 태스크로 주기적 엑셀 다운로드 + 파싱
- DB에 `gp_statistics` 테이블 추가

### Phase 3: 장기 고도화 (1개월+)

**DART 펀드공시 자산운용보고서 파싱**

- OpenDartReader 라이브러리 활용
- 운용사별 운용보고서 검색 → PDF/HTML 파싱
- 투자 포트폴리오, 수익률, 섹터 배분 데이터 추출

---

## 5. 핵심 주의사항

1. **API 데이터 범위 검증 필수**: 공공데이터포털 API에 "에이티유파트너스" 직접 검색하여 데이터 포함 여부 확인 필요
2. **2021년 사모펀드 체계 개편**: 경영참여형(PEF) + 전문투자형 → 기관전용 + 일반 사모펀드로 재편. API 데이터가 이를 반영하는지 확인
3. **FreeSIS가 가장 확실한 소스**: "기관전용 사모펀드" 카테고리가 명시적으로 존재하나, API 미제공으로 자동화 난이도 높음
