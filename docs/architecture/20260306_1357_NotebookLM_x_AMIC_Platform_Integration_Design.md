# NotebookLM x AMIC Platform 활용 방안 설계

> 작성일: 2026-03-06 13:57 KST
> 상태: 아이디어 수준 설계 (구현 전)

## Context

AMIC x PETRA Platform은 M&A 딜 전체 라이프사이클을 관리하는 플랫폼으로, 4개 백엔드 모듈(deal-mgmt, FDD, IM, KIIS)에서 Claude/GPT/Gemini를 활용한 대량 문서 분석·생성을 수행 중이다. 현재 **가장 큰 토큰 비용**은 IM 내러티브 생성(14개 섹션 LLM 호출 + RAG), deal-mgmt의 문서 AI 추출(5단계 파이프라인), FDD의 QoE 분석 순이다.

**NotebookLM**은 Google의 무료 RAG 도구로, 문서를 업로드하면 자체 인덱싱 후 자연어 질의응답·요약·구조화가 가능하다. 공식 API는 없으나 비공식 Python 래퍼로 프로그래밍적 접근이 가능하다. 핵심 가치는 "비용이 많이 드는 대량 문서 분석을 무료 도구에 위임"하는 패턴이다.

## 활용 방안 종합 (4대 목적 × 모듈별)

### A. 토큰 비용 절감

#### A1. VDR 문서 자동 분류 — NotebookLM 1차 분류 + LLM 확인

| 항목 | 현재 | NotebookLM 적용 후 |
|------|------|-------------------|
| 분류 방식 | 키워드 스코어링(60점 미만 → LLM 호출) | NotebookLM에 VDR 폴더 정의서 + 샘플 업로드 → 새 문서를 "이 문서는 어떤 카테고리?" 질의 → 결과를 스코어링과 결합 |
| LLM 호출 | 분류 실패 시 Claude Haiku 호출 | NotebookLM이 1차 판단 → 신뢰도 높으면 LLM 스킵 |
| 예상 절감 | — | 스코어링 60점 미만 문서의 **70~80%** LLM 호출 절감 |

**작동 흐름**:
```
VDR 업로드 → 스코어링 엔진(기존) → 60점 이상: 바로 분류
                                   → 60점 미만: NotebookLM 질의
                                     → 높은 신뢰도: NotebookLM 결과 채택
                                     → 낮은 신뢰도: Claude Haiku 호출(기존)
```

#### A2. IM 내러티브 생성 — 산업/시장 분석 섹션 위임

| 항목 | 현재 | NotebookLM 적용 후 |
|------|------|-------------------|
| RAG | Pinecone 벡터 DB (유료) | 산업 보고서/시장 자료를 NotebookLM 노트북에 업로드 → 무료 RAG |
| 시장 분석 | Claude/GPT가 직접 생성 ($0.5~1.0/문서) | NotebookLM이 시장 규모, 트렌드, 경쟁사 분석 초안 생성 → LLM은 최종 편집만 |
| 대상 섹션 | — | `market_overview`, `investment_highlights`, `company_overview` (팩트 중심 섹션) |

**적합한 IM 섹션** (토큰 절감 효과 높은 순):
1. **market_overview** — 산업 보고서 기반, 팩트 중심 → NotebookLM 최적
2. **company_overview** — DART 공시 데이터 기반 → NotebookLM 질의로 대체 가능
3. **investment_highlights** — 여러 소스 종합 → NotebookLM 요약 후 LLM 보강

**부적합 섹션** (LLM 유지):
- `executive_summary` — 전체 문서 톤/전략 반영 필요
- `deal_overview` — 딜 구조 분석, 판단력 필요
- `financial_analysis` — 정밀 계산 + 해석 필요

#### A3. FDD QoE 코멘터리 — 분석 근거 자료 위임

| 항목 | 현재 | NotebookLM 적용 후 |
|------|------|-------------------|
| 방식 | Jinja2 템플릿 + LLM 보강 | 과거 QoE 보고서들을 NotebookLM에 축적 → "이 조정항목과 유사한 과거 사례는?" 질의 |
| 효과 | — | 과거 사례 기반 코멘터리 자동 생성 → LLM 호출 횟수 감소 |

#### A4. 문서 AI 추출 — 분류 단계 위임

현재 5단계 파이프라인 중 **2단계(문서 분류)**를 NotebookLM에 위임:
- NDA/LOI/SPA 등 9개 카테고리 분류 → NotebookLM에 카테고리별 샘플 문서 + 정의서 업로드
- "이 문서는 어떤 유형인가?" 질의 → 분류 결과 반환
- **3단계(구조화 추출)은 LLM 유지** (정밀도 필요)

### B. 신규 기능 확장

#### B1. 딜 간 교차 비교 분석 (Cross-Deal Intelligence)

현재 불가능한 기능. 각 딜은 독립적으로 관리되며 딜 간 패턴 비교가 없음.

**NotebookLM 활용**:
- 완료된 딜들의 VDR 핵심 문서(IM, 계약서, 실사 보고서)를 NotebookLM 노트북에 축적
- "최근 3년간 제조업 M&A에서 가장 빈번한 QoE 조정 항목은?" 질의
- "이 딜의 SPA 조건과 유사한 과거 딜은?" 비교 분석
- 딜 성공/실패 패턴 도출

**비즈니스 가치**: 어드바이저의 경험을 조직 지식으로 체계화 → 시니어 의존도 감소

#### B2. 자동 시장 리서치 파이프라인

**현재**: 어드바이저가 수동으로 산업 보고서, 뉴스, 공시 등을 검색·정리

**NotebookLM 파이프라인**:
```
Claude Code(검색 에이전트)
  → 산업 보고서 PDF/웹페이지 수집
  → NotebookLM 노트북에 자동 업로드
  → "이 산업의 시장 규모, 성장률, 주요 플레이어를 정리해줘" 질의
  → 구조화된 리서치 결과를 플랫폼 DB에 저장
```

적용 대상:
- **KIIS 모듈**: VC/PE 운용사 리서치 (뉴스 + 공시 종합 분석)
- **deal-mgmt**: 신규 딜 소싱 시 대상 기업 산업 분석
- **IM 모듈**: 투자설명서 시장 분석 섹션 자료 수집

#### B3. 규제/컴플라이언스 Knowledge Base

**NotebookLM 활용**:
- M&A 관련 법령, 가이드라인, 판례를 NotebookLM에 업로드
- "이 거래에서 공정거래법상 기업결합 신고 의무가 있는가?" 질의
- 인허가 요건(permits) 분석에 활용 — 현재 knowledge base 기반

#### B4. Audio Overview — 딜 상황 오디오 브리핑

NotebookLM의 **Audio Overview** 기능 활용:
- 딜 주간 업데이트 문서를 NotebookLM에 업로드
- 팟캐스트 형태의 오디오 브리핑 자동 생성
- 어드바이저가 출퇴근 중 딜 상황을 청취

### C. 사용자 경험 개선

#### C1. VDR 자연어 Q&A (Deal Room AI Assistant)

**핵심 기능**: 딜 담당자가 VDR에 업로드된 수백 개 문서에 대해 자연어로 질의

**현재 문제**: VDR에 수백 개 파일이 있어도, 필요한 정보를 찾으려면 파일을 하나하나 열어봐야 함

**NotebookLM 활용**:
```
딜 생성 → VDR 폴더 자동 생성 → 문서 업로드 시 NotebookLM 노트북에 동기화

사용자 질의 예시:
- "대상 기업의 최근 3년 매출 추이는?"
- "NDA에서 비경쟁 조항(Non-Compete) 기간은?"
- "이 딜의 잠재적 법적 리스크를 요약해줘"
- "모든 입찰서의 제안 가격을 비교해줘"
```

**장점**: 소스 기반 답변 → 환각(Hallucination) 최소화, 출처 명시

#### C2. 딜 대시보드 자동 인사이트

- 주간/월간 딜 진행 상황을 NotebookLM이 자동 요약
- "이번 주 VDR에 새로 업로드된 문서 중 주의가 필요한 것은?"
- 타임라인 이벤트 + VDR 업로드 + 회의록을 종합한 인사이트

#### C3. 실사 체크리스트 자동 완성도 분석

현재 DD 체크리스트(FDD/LDD/TDD)는 수동으로 항목별 완료 여부를 관리.

**NotebookLM 활용**:
- VDR 문서 전체를 NotebookLM에 업로드
- "FDD 체크리스트 중 아직 VDR에 해당 자료가 없는 항목은?" 질의
- 미제출 자료 자동 감지 → RFI(정보요청서) 자동 생성 연계

---

### D. 내부 운영 효율화

#### D1. 어드바이저 리서치 워크플로우 자동화

**현재 워크플로우** (수동, 2~4시간 소요):
1. 대상 기업 산업 파악
2. 산업 보고서/뉴스/공시 수집
3. 경쟁사 분석
4. 시장 규모/트렌드 정리
5. IM/티저에 반영

**자동화 워크플로우** (30분 이내):
```
어드바이저: "삼성바이오로직스 산업 분석해줘"
  → Claude Code: DART 공시 + 뉴스 + 산업 보고서 자동 수집
  → NotebookLM: 수집 자료 업로드 + 종합 분석
  → 결과: 구조화된 산업 분석 보고서 (시장 규모, CAGR, 경쟁 구도, 규제 환경)
  → IM 모듈에 자동 반영
```

#### D2. 회의 준비 자동화 (Meeting Prep)

- 다음 회의 관련 문서(VDR 자료 + 이전 회의록 + RFI 응답)를 NotebookLM에 업로드
- "다음 실사 회의에서 확인해야 할 핵심 질문 5가지는?" 질의
- 회의 안건 자동 생성

#### D3. 지식 축적 및 신입 온보딩

- 완료된 딜의 교훈(Lessons Learned)을 NotebookLM에 체계적으로 축적
- 신입 어드바이저가 "M&A 실사에서 가장 빈번한 이슈는?" 같은 질문으로 학습
- **조직 지식의 민주화** — 시니어 경험이 주니어에게 자동 전달

#### D4. KIIS 뉴스/공시 종합 분석

현재 KIIS는 규칙 기반 NLP(kiwipiepy)로 뉴스 감성 분석을 수행.

**NotebookLM 보강**:
- 특정 운용사(GP) 관련 뉴스 + DART 공시를 NotebookLM에 업로드
- "이 운용사의 최근 투자 전략 변화는?" 질의
- 단순 감성 점수(-1~+1)를 넘어 **정성적 인사이트** 제공

## 기술적 제약사항 및 리스크

### NotebookLM 제약
| 제약 | 영향 | 대응 |
|------|------|------|
| 공식 API 없음 (비공식 래퍼) | 안정성 불확실, 언제든 차단 가능 | 폴백 로직 필수 (NotebookLM 실패 시 기존 LLM 파이프라인 사용) |
| 노트북당 소스 50개 제한 | 대규모 VDR(수백 개 파일) 수용 불가 | 딜당 핵심 문서만 선별 업로드 / 여러 노트북 분할 |
| 소스당 500K 단어 제한 | 대형 PDF(사업보고서 등) 일부 초과 가능 | 문서 분할 전처리 |
| Google 계정 로그인 필요 | 서버 환경에서 인증 관리 복잡 | 서비스 계정 or 초기 1회 인증 후 토큰 유지 |
| 무료 한도 불명확 | 대량 사용 시 제한 가능 | 사용량 모니터링 + Google AI Studio/Gemini API 폴백 |
| 응답 속도 불안정 | 실시간 UX에 부적합 | 비동기 배치 처리, 결과 캐싱 |

### 대안 기술 비교
| 도구 | 비용 | API | RAG 품질 | 적합 용도 |
|------|------|-----|---------|----------|
| **NotebookLM** | 무료 | 비공식 | ★★★★ | 배치 분석, 리서치, Q&A |
| **Google AI Studio** | 무료~저가 | 공식 | ★★★ | 프로토타이핑, 간단 분석 |
| **Gemini API (1.5 Pro)** | 저가 ($0.00125/1K) | 공식 | ★★★★ | 대량 문서 처리 (1M 토큰 컨텍스트) |
| **자체 RAG (Pinecone)** | 중가 | 완전 제어 | ★★★★★ | 프로덕션 안정성 필요 시 |

### 권장 하이브리드 전략
```
[1단계] NotebookLM으로 프로토타입 + 효과 검증
[2단계] 효과 입증된 기능 → Gemini 1.5 Pro API로 마이그레이션 (안정성 확보)
[3단계] 미션 크리티컬 기능 → 자체 RAG 유지 (IM 재무 분석 등)
```

## 결론

NotebookLM의 가장 큰 활용 가치는 **"대량 문서 기반 질의응답을 무료로 수행"**하는 것이다. 현재 플랫폼에서 가장 즉각적인 임팩트를 줄 수 있는 3가지 P1 방안:

1. **IM 시장분석 섹션 위임** (A2) — 가장 높은 토큰 비용 절감
2. **VDR 자연어 Q&A** (C1) — 가장 높은 사용자 가치
3. **VDR 문서 분류 위임** (A1) — 기존 파이프라인에 자연스럽게 통합

장기적으로는 **딜 간 교차 비교**(B1)와 **리서치 자동화**(D1)가 어드바이저리 비즈니스의 핵심 경쟁력이 될 수 있다.
