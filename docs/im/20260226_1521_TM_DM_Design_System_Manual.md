# AMIC x PETRA -- TM/DM PPT 디자인 시스템 매뉴얼

> 4개 PPTX 템플릿(NX3 DM, SPICY TM, SWITCH TM, YTN DM) 메타데이터 프로그래밍 분석 결과
> 분석일: 2026-02-26 15:21
> 분석 도구: python-pptx 1.0.2, PPTX XML 직접 파싱 (EMU 원시값 기반)

---

## 사전 확인 사항 (Technical Capability Declaration)

### 1. PPTX 메타데이터 파싱 해상도 및 슬라이드 마스터/레이아웃 인식

**지원 수준: 높음 (python-pptx 1.0.2 기반)**

- 슬라이드 크기, 마스터, 레이아웃, 플레이스홀더를 EMU(English Metric Unit) 정밀도로 파싱 가능
- 레이아웃별 플레이스홀더 인덱스, 좌표, 크기를 정확히 추출 완료
- 테마 XML에서 폰트 스킴(majorFont/minorFont) 및 컬러 스킴(12색) 완전 추출
- **한계**: 슬라이드 마스터 배경이 이미지(blipFill)인 경우, 이미지 rId와 존재 여부만 확인 가능하며 이미지 자체의 시각적 내용은 비전 모델 없이는 판단 불가. 단, 레이아웃별 배경 이미지 유무와 크기(27.52x19.05cm 전체 커버)는 확인됨.

### 2. 비전 모델의 수치 추출 정밀도

**정밀도: 메타데이터 단위(EMU -> pt, cm, 인치) 직접 추출**

- 본 분석은 시각적 비전 모델이 아닌 **PPTX XML 직접 파싱**으로 수행됨
- 따라서 모든 수치는 근사치 픽셀 추정이 아닌 **PPT 내부 메타데이터 원본 단위**에서 변환한 정확한 값
- 변환 공식: 1인치 = 914,400 EMU, 1pt = 12,700 EMU, 1cm = 360,000 EMU
- 폰트 크기, 도형 좌표, 여백, 테두리 두께 등 모두 EMU 원시값에서 산출
- **한계**: `(inherited)` 표기된 폰트 속성은 테마/마스터에서 상속된 값으로, 런타임 렌더링 시 적용되는 실제 값은 PowerPoint 엔진의 상속 체인에 의존

### 3. 빈 PPTX 템플릿 자동 생성 가능 여부

**가능: python-pptx로 직접 생성 가능**

- 원본 PPTX에서 마스터/레이아웃을 복제한 후 콘텐츠만 공란화하는 방식으로 생성
- 생성 스크립트: `im/scripts/generate_blank_templates.py`
- 생성물: `im/templates/AMIC_TM_Template.pptx` (25슬라이드), `im/templates/AMIC_DM_Template.pptx` (7슬라이드)

#### 특수 불릿 -- Pretendard `->` (화살표)

| 속성 | 값 |
|------|-----|
| 글머리 문자 | `->` (U+2192) |
| 불릿 폰트 | Pretendard |
| 왼쪽 여백(marL) | **0.476 cm** |
| 내어쓰기(indent) | **-0.476 cm** |
| 빈도 | **4건** (결론/시사점 강조) |

### 3.3 불릿 수준 구조 다이어그램

```
|<- 0.476cm ->|<- 0.521cm ->|
|             |             |
u/\u00a7 1수준 본문 텍스트 (Wingdings)
              - 2수준 하위 항목 (Pretendard -)
|<- 0.997cm ->|
```

## 4. 표(Table) 서식

### 4.1 공통 표 스타일

| 속성 | 값 |
|------|-----|
| **세로 테두리** | **없음** (좌/우 lnL/lnR = noFill) |
| **가로선 (헤더 하단)** | `0.5pt #6A6A6A solid` (실선) |
| **가로선 (데이터 행)** | `0.5pt #6A6A6A dash` (대시선) |
| **가로선 (마지막 행)** | `0.5pt #6A6A6A solid` (실선 복귀) |
| **firstRow 속성** | `1` (True) -- 헤더 행 별도 스타일 |
| **bandRow 속성** | `1` (True) -- 줄무늬 행 활성화 |
| **셀 세로 정렬(anchor)** | `ctr` (수직 중앙) |

> **핵심 패턴**: 좌우 테두리 없음 + 상하 실선/대시선 교차 = 깔끔한 수평 줄무늬 표

### 4.2 헤더 행 (Header Row)

| 속성 | 값 |
|------|-----|
| 배경색(fill) | **`#26C260`** (AMIC Green) |
| 폰트색 | **scheme bg1** (`#FFFFFF`) |
| 폰트 크기 | **10pt** (일반) / **9pt** (재무제표) / **8pt** (DM 캡테이블) |
| 굵기 | **Bold** (항상) |
| 셀 여백 | L=0.1cm, R=0.1cm, T=0.0cm, B=0.0cm |

### 4.3 데이터 행

| 속성 | 값 |
|------|-----|
| 배경색 | **noFill** (투명/흰색) |
| 강조 행 배경 | **`#E6FDD6`** (연한 그린) -- 소계, 합계, 강조 항목 |
| 폰트색 | **scheme tx1** (dk1=`#2A2A2A`) |
| 카테고리 라벨색 | **`#1C8F57` Bold** 또는 **`#26C260` Bold** -- 행 그룹 제목 |
| 폰트 크기 | **10pt** (일반) / **9pt** (재무제표) / **8pt** (DM 소형 표) |
| 셀 여백 | L=0.1cm, R=0.1cm, T=0.0cm, B=0.0cm (YTN 법률: 0.2cm) |
| 하위 항목 들여쓰기 | marL = **0.4cm** (재무제표 소항목) |

### 4.4 표 유형별 규격

| 표 유형 | 위치 | 크기 | 비고 |
|---------|------|------|------|
| **데이터 테이블** (재무) | (1.258, 6.024)cm 또는 듀얼 패널 | 12.2x10~13cm | 소계행 bold `#1C8F57` |
| **회사 개요** | (1.258, 6.024)cm 좌측 패널 | 12.2x5~10cm | gridSpan=4 병합 |
| **TOC 테이블** | (0.957, 6.024)cm | 9.8x4.4cm | +mj-lt 14pt, `#0F3A32` |
| **법률/세무 의견** | (1.258, 6.024)cm | 25.0x8~9cm | 전체 너비, 셀여백 0.2cm |
| **캡 테이블** | (1.258, 6.024)cm | 17.2x11.25cm | 8pt 소형 |

### 4.5 TOC 테이블 고유 서식

| 속성 | 값 |
|------|-----|
| 위치 | `l=0.957cm, t=6.024cm` |
| 크기 | `9.8 x 4.4cm` |
| 구조 | 4행 x 2열 (번호 + 섹션명) |
| 현재 섹션 | bg=scheme:bg1 (흰색), font color `#0F3A32` |
| 다른 섹션 | bg=noFill, font color scheme:bg1 (흰색) |
| 테두리 | 상단 noFill, 하단만 `0.75pt scheme:bg1` |

### 4.6 셀 병합 패턴

- **gridSpan**: 2~5 열 병합 (헤더 제목 영역, 회사개요 값 셀)
- **rowSpan**: 2행 병합 (카테고리 그룹핑)
- 병합은 주로 헤더/카테고리 레이블에서 사용
