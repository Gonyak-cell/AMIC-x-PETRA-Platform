# 플랜 작성 후 Codex 리뷰 자동 질문

> **핵심**: 플랜 파일을 작성하면 반드시 사용자에게 Codex 리뷰 여부를 질문한다.

## 적용 시점

플랜 파일(`.claude/plans/*.md` 또는 `~/.claude/plans/*.md`)을 Write 도구로 작성한 **직후** 자동 적용.

## 필수 행동

플랜 파일을 Write한 후, **반드시** AskUserQuestion 도구를 사용하여 사용자에게 질문한다:

- **질문**: "Codex GPT-5.4 (reasoning: xhigh) 리뷰를 받으시겠습니까?"
- **옵션 1**: "예, Codex 리뷰 실행" (Recommended)
- **옵션 2**: "아니오, 건너뛰기"

### 사용자가 "예"를 선택한 경우

1. 방금 작성한 플랜 파일 경로를 인자로 `/plan-review` 스킬을 실행한다.
2. Codex 리뷰 원문을 그대로 사용자에게 보여준다.
3. 리뷰 피드백 기반으로 플랜 수정 여부를 추가 질문한다.

### 사용자가 "아니오"를 선택한 경우

1. 리뷰 없이 다음 단계로 진행한다.

## 예외

- 플랜 파일을 Edit(수정)한 경우에는 질문하지 않는다 (최초 Write 시에만 적용).
- 이미 `/plan-review`를 실행한 직후에는 중복 질문하지 않는다.
- 사용자가 명시적으로 "리뷰 건너뛰기" 또는 "Codex 리뷰 안 받겠다"고 말한 경우 해당 세션에서는 질문하지 않는다.
