# 성능 벤치마크

대상: $ARGUMENTS (fdd / kiis / im / all)

## 1단계: API 응답 시간
- 주요 엔드포인트별 응답 시간 측정 (p50/p95/p99)
- 동시 요청 처리 성능 (10/50/100 concurrent)
- 파일 업로드 처리 시간 (다양한 크기)

## 2단계: DB 쿼리 성능
- 주요 쿼리 EXPLAIN ANALYZE 실행
- N+1 쿼리 패턴 탐지
- 인덱스 활용 현황 점검
- 커넥션 풀 상태 확인

## 3단계: 모듈별 특화 분석
- **FDD**: Excel 파싱 속도 (1K/10K/100K행), 엔진 계산 시간
- **KIIS**: DART/KOFIA API 호출 성능, Redis 캐시 히트율
- **IM**: Celery 태스크 처리 시간, 차트 렌더링 속도

## 4단계: 메모리 프로파일링
- 대용량 데이터 처리 시 메모리 사용량
- ORM 객체 로딩 메모리 효율성
- 메모리 누수 패턴 탐지

## 5단계: 보고서
- @performance-profiler 에이전트로 분석
- 병목 지점 식별 및 우선순위 부여
- 개선 제안 (구체적 코드 변경 포함)
- API 응답 시간 SLA 충족 여부

### 응답 시간 목표
| Endpoint Type | Target | Max |
|--------------|--------|-----|
| 단순 조회 | < 200ms | 500ms |
| 리스트 조회 | < 500ms | 1s |
| 생성/수정 | < 500ms | 2s |
| 파일 업로드 | < 5s | 30s |
